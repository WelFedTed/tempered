Storage system

Packs stand on their long edge in drawer lanes, filed by fit-group code. A 3D-printed divider with a label tab marks the start of each group, so finding glass for a customer's phone takes two steps: look it up, then pull the tab.

Concept renders. They show an early 3-digit code format; current codes have 4 digits (e.g. SAM-1476-C).

How to set it up

1. Plan the drawers

  • Give each drawer a range: phones from your busiest brands first, then tablets, wearables and handhelds.
  • Within a lane, file groups in code order. Codes run oldest first, so new models go at the back.
  • Put rarely sold groups in an overflow drawer, still in code order.

2. Label the dividers

  • One divider per fit group, with a 50 × 25 mm tab label from the label maker.
  • Print one tab per glass type you carry: Clear, Privacy or Matte.
  • Mix left, centre and right tab dividers so every label stays visible.

3. Sticker the packs

  • Put a 40 × 30 mm pack sticker on each pack as it arrives.
  • The code tells you where a returned or loose pack belongs.
  • The sticker lists every model it fits, so you can sell one pack for any of them.

3D-printed dividers

Packs file in behind each divider; a small foot on the back stops it tipping. Print flat with the label face down. No supports. PLA or PETG at 0.2 mm layers.

Sized for phone packs of about 180 × 95 mm. Tablet dividers are 200 mm wide for packs up to 280 × 200 mm. For other pack sizes, open the OpenSCAD file and set pack_long and pack_short.
