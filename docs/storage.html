Storage system

Look it up.
Pull the tab.

Packs stand on their long edge in drawer lanes, filed by fit group code. A 3D-printed divider with a label tab marks the start of each group.

Galaxy S24→SAM-1468-C

Concept renders. They show an early 3-digit code; current codes have 4 digits, like SAM-1468-C.

Set it up in three passes

01 · Plan the drawers

  • Give each drawer a range: phones from your busiest brands first, then tablets, wearables and handhelds.
  • Within a lane, file groups in code order. Codes run oldest first, so new models go at the back.
  • Put rarely sold groups in an overflow drawer, still in code order.

02 · Label the dividers

  • One divider per fit group, with a 50 × 25 mm tab label from the label maker.
  • Print one tab per glass type you carry: Clear, Privacy or Matte.
  • Mix left, centre and right tab dividers so every label stays visible.

03 · Sticker the packs

  • Put a 40 × 30 mm pack sticker on each pack as it arrives.
  • The code tells you where a returned or loose pack belongs.
  • The sticker lists every model it fits, so one pack sells for any of them.

3D-printed dividers

PRINTFlat, label face down. No supports. PLA or PETG, 0.2 mm layers.
PHONEFor packs about 180 × 95 mm. A foot on the back stops it tipping.
TABLET200 mm wide, for packs up to 280 × 200 mm.

Other pack sizes: open the OpenSCAD file and set pack_long and pack_short.
