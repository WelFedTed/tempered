How codes work

APP-1013-C

APP is the brand, 1013 is the fit group and C is the glass type: C Clear, P Privacy, M Matte. Every model in a group takes the same glass, so one label covers them all.

Number ranges

0001+Misc, incl. universal round watch glass (UNI)
1001+Phones
2001+Tablets and e-readers
3001+Wearables
4001+Handheld consoles

Within a brand, groups are numbered oldest first.

Confirmed vs unverified

✓ Confirmed means a glass maker or seller lists these models together. Unverified means the models match on body and screen specs, or the model stands alone. Test the fit before swapping.
